✨ Características Principales

Funcionalidades

✅ Sistema de autenticación con roles (Administrador/Paciente)

✅ Gestión de especialidades médicas con imágenes

✅ Gestión de profesionales/médicos por especialidad

✅ Sistema de turnos con asignación automática

✅ Gestión de obras sociales

✅ Gestión de usuarios conectada a DummyJSON API

✅ Modo oscuro/claro persistente

✅ Diseño responsive (móvil, tablet, desktop)

Tecnologías

Frontend: HTML5, CSS3, JavaScript (Vanilla)

Framework CSS: Bootstrap 5.3.8

Iconos: Font Awesome 7.0.1
Alertas: SweetAlert2

API Externa: DummyJSON para gestión de usuarios

Almacenamiento: LocalStorage y SessionStorage

Imágenes: Optimizadas en Base64 (sin carpeta física)

📡 Integración con DummyJSON API

Gestión de Usuarios

El módulo de Gestión de Usuarios está integrado con la API REST externa DummyJSON para demostrar el consumo de servicios web.
